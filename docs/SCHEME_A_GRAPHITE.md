# A 石墨安静版

在原有 AppKit 布局上实施：顶部操作栏、左侧最优路由卡、右侧订阅矩阵、下方十列表格、底部状态与切换操作区。订阅选择、前 N 项、搜索、筛选、加压验证、定时和切换入口保留原位。

## 颜色与材质

所有自绘控件共享 `MultiPalette` 动态颜色，随系统外观切换。内容使用不透明面色和单层细边框，去掉背景光晕、玻璃高光、白色内描边和多色吞吐渐变。只将「开始测速」设为实色主按钮；选中订阅、筛选项和行使用低亮度蓝灰底。

| 用途 | 深色 | 浅色 |
| --- | --- | --- |
| 窗口背景 | `#14171B` | `#F3F5F8` |
| 顶部操作栏 | `#1A1E23` | `#F9FAFC` |
| 卡片与表格 | `#1C2026` | `#FFFFFF` |
| 控件底色 | `#232932` | `#EDF1F6` |

`Tests/test_multi_app_ui.py` 从 AppKit 实际解析出的颜色计算对比度，覆盖两种外观中的普通面、控件面、选中行、结果反馈面及主按钮，共 74 组配对。普通文字要求至少 4.5:1。启用系统「增强对比度」时提高控件描边对比度；内容本身不依赖透明材质。

## 状态反馈

- 进度条按实际处理节点数推进，单次过渡 450 ms，不做循环扫描或闪烁。
- 最优路由数字直接显示最终值；结果变化时背景反馈在 300 ms 内结束。
- 测速期间保持行序，卡片独立计算当前最高分；每阶段结束后按综合分排序。测速期间暂不响应表头排序，避免更新打断阅读。
- 就绪、测试中、失败等状态保留文字；颜色只作补充。
- 系统「减少动态效果」启用后取消进度过渡及卡片反馈，继续显示真实进度和数值。
- 状态倒计时按秒更新，空闲时不再每秒刷新 20 次动画。
- 结束或停止后刷新可见行的交互状态，避免复选框停留在测速时的禁用样式。

保留 1240 × 800 默认窗口和 1080 × 700 最小内容尺寸。窄窗口允许搜索框在 120–196 pt 之间收缩，参数控件按内容缩小间距。

## 验证范围

配色回归使用合成数据，不读取真实订阅，也不运行下载或切换。打包后另以安装路径中的正式应用做桌面验收；启动后的运行时桥接继续沿用现有实现。

```sh
python3 -B Tests/test_multi_app_ui.py
python3 -B Tests/test_graphite_native_ui.py
```

第二项需要 macOS 的 WindowServer，会构造真实 AppKit 视图并检查默认/最小窗口、搜索空态、行序、数字、进度与减少动态效果；使用临时裸可执行文件，完成后自动移除。加上 `--output /绝对路径/验收目录` 可保留合成截图和 `native-qa.json`。
