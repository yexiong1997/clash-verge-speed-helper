- `verified-worker.patch` is the source of this project's modifications, derived from the upstream speedtester architecture and supplied for application to the pinned source. It adds a minimal JSON-v1 entry point, private initialization, bounded downloads and explicit completeness checks; it also prevents JSON serialization of upstream `Result.ProxyConfig`. The patch also validates endpoint fields before Mihomo adapter construction using conservative Hysteria/Hysteria2/Mieru range grammars. It rejects SSH and WireGuard entirely, independent of build tags, and rejects every HTTP-node custom-header field, including decoder aliases, rather than risk CONNECT header injection. Exact restrictions are in `CONTRACT.md`. Endpoint validation is not a private-IP or LAN egress sandbox: use trusted subscriptions and targets, since reachable arbitrary endpoints may be contacted. The source patch and upstream source together are required to build the worker; no worker binary is supplied in the repository.
- Go **1.25.0** archive hashes are independently pinned in `Scripts/build-verified-worker.sh` and checked against [official go.dev version metadata](https://go.dev/dl/?mode=json&include=all), then the downloaded archive is SHA-256-checked before extraction. Upstream `go.mod` and `go.sum` remain unchanged, with Go checksum verification and the public checksum database enabled. The default public module mirror is `https://goproxy.cn`; set `VERIFIED_WORKER_GOPROXY=https://proxy.golang.org` to select the other permitted mirror.
